# paper/sections/

Each section of your paper is one `.typ` file in this directory. The
`draft` skill (stance: write) writes and revises them, and maintains the
`#include` list in `paper/main.typ` so a new section becomes part of the
compiled document.

Standard files for a research paper:
- `abstract.typ`
- `introduction.typ`
- `methods.typ`
- `results.typ`
- `discussion.typ`
- `conclusion.typ`

A thesis or technical report uses different filenames matching the
chapter structure. The names are determined by the outline.

`abstract.typ` ships as a placeholder; the rest appear as you draft them.
